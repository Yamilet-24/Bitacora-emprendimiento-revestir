# Bitácora de Planeación de un Emprendimiento: ReVestir

## Descripción
ReVestir es un emprendimiento ficticio de tienda online que vende ropa reciclada y de segunda mano, seleccionada y renovada. Este repositorio es la bitácora de su planeación.

## Objetivo
Documentar la planeación inicial del negocio: propuesta de valor, público objetivo y plan de marketing básico, dejando evidencia del proceso con GitHub.

## Herramientas utilizadas
- GitHub (repositorio, issues y commits)
- GitHub Projects (tablero de tareas)
- Markdown (documentación)

## Integrantes

## Estado inicial
Proyecto en etapa de planeación. Estructura y documentos base en creación.

## Organización del trabajo
Las tareas se registran como issues y se organizan en un tablero de GitHub Projects con los estados: Pendiente, En proceso, En revisión y Completado. Cada avance se guarda en commits con mensajes claros.
